\# Sistema de Gestión de Biblioteca



Este proyecto permite registrar libros, consultar cuáles están disponibles y llevar un control sencillo de los préstamos.



Su propósito es facilitar la organización de una pequeña biblioteca.



\## Instalación



1\. Clonar el repositorio desde GitHub.

2\. Abrir la carpeta del proyecto.

3\. Instalar las dependencias necesarias.

4\. Ejecutar el programa.



\## Tecnologías utilizadas



\- Python

\- Visual Studio Code

\- Git y GitHub

\- Markdown
